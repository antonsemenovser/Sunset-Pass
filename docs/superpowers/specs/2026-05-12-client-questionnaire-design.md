# Sunset Pass — Опросник для клиента: Design Doc

**Дата:** 2026-05-12  
**Проект:** Sunset Pass — система бронирования огороженного парка для собак (Финляндия)  
**Задача:** Веб-форма для сбора требований от клиента перед разработкой основного продукта

---

## Контекст

Клиент владеет огороженным парком в Финляндии. Идея: люди бронируют слот времени онлайн, оплачивают, получают PIN-код, приходят, вводят код на панели — ворота открываются. Собака гуляет по всему парку без привязи. Слот заканчивается — ворота закрываются, заходит следующий.

Конкретного ТЗ нет. Нужно сначала собрать требования через опросник.

---

## Архитектура

- **Frontend:** HTML + CSS + JS (статика)
- **Хостинг:** Netlify (бесплатно), деплой через GitHub
- **База данных:** Airtable (бесплатный тариф) — принимает ответы через API
- **Email:** EmailJS — при отправке формы шлёт письмо на anton.semenov.ser@gmail.com
- **Админка:** Airtable (airtable.com) — все ответы видны в таблице без дополнительной разработки

Нет сервера. Нет затрат на старте.

## Содержание опросника (12 вопросов)

### О парке
1. Какой размер парка? (площадь, примерно)
2. Сколько человек максимум могут быть в парке одновременно?
3. Какова минимальная и максимальная длительность одного слота?
4. Часы работы парка (по дням недели)?

### О бронировании
5. Как клиент хочет принимать оплату? (онлайн карта, наличные, счёт?)
6. Нужна ли возможность отмены бронирования? За сколько часов?
7. Нужна ли регистрация пользователя или достаточно имя + email?

### О воротах
8. Какое оборудование уже есть на воротах или нужно закупить?
9. PIN-код — кто его генерирует, вы или система автоматически?

### О дизайне и языке
10. Есть ли логотип, фирменные цвета, название парка?
11. На каком языке должен быть сайт/приложение? (финский, английский, оба?)

### О сроках
12. Когда нужен готовый продукт?

## Дизайн формы

- Минималистичный стиль: белый фон, тёмный текст
- Каждый вопрос: заголовок + textarea для ответа + необязательное поле "комментарий"
- Прогресс-бар сверху
- Кнопка "Отправить" внизу
- После отправки: страница благодарности
- Адаптивный дизайн (мобильные устройства)
